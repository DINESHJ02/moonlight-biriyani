# Tirutani Moon Light Briyani

Static website for Tirutani Moon Light Briyani, Tiruttani. Single-page app with Home, Menu, Reviews and Contact views, a cart, and WhatsApp ordering.

## Stack
HTML5, CSS3, vanilla JavaScript. Fonts via Google Fonts, icons via Font Awesome CDN.

## Run locally
Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

## Deploy (GitHub Pages)
Repo Settings → Pages → Deploy from branch → `main` / root.
